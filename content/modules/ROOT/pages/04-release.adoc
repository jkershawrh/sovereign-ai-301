= 4. Authorize one resource, not inference

== Show
Resource policy names one exact protected resource for an appraised identity.

== Learn
An allowed rehearsal emits a hash receipt only. It releases no key and grants no
caller, prompt, model, or inference permission.

== Do
[source,bash,role="execute"]
----
python3 - <<'PY'
import json
d=json.load(open('/tmp/northstar-301-allowed.json'))
print(json.dumps({'resourcePolicy':d['resourcePolicy'],'keyRelease':d['keyRelease']},indent=2))
PY
----
[source,bash,role="execute"]
----
python3 - <<'PY'
import json
d=json.load(open('/tmp/northstar-301-allowed.json'))
assert d['keyMaterialReleased'] is False
assert d['inferenceAuthorization']['allowed'] is False
assert d['modelInvoked'] is False
print('PASS: zero model executions; resource and inference authority remain separate')
PY
----

== Prove
The customer outcome remains protected inference, but this lab honestly proves
only the contract boundary—not a model call.
